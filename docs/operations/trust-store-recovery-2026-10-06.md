# Support and Ops transaction recovery — October 6, 2026

The Trust API's actor transactions and startup role checks now use the existing original-client settlement helper already used by Trust worker acknowledgments. Checkout must have an actual finite original pool budget. The helper retains the exact client through known rollback or transport close/discard, bounds the whole transaction to five seconds, and refuses uncertain commits. The actor account remains transaction-local; shorter existing statement and lock timeouts are preserved. Startup role checks use one read-only transaction with the same original non-owner/RLS checks. Genuine checkout failures now return a retryable `trust_connection_unavailable` (503) with a private cause.

## Personally operated evidence

Actual non-owner API and worker role checks succeeded. A successful actor transaction retained original two-second statement and 500ms lock timeouts; its account setting cleared at commit. An actual inserted command followed by a domain failure rolled back, preserving that domain error and allowing safe reuse. Exhausting a real one-client pool returned in 502ms with no acquisition left queued. A sequence of actual one-second SQL sleeps exceeded the whole-transaction budget at 5002ms: the client was discarded, the uncommitted insert did not persist, and the next operation used a different PID. The original server PID was still present at the immediate transport-close sample and absent when checked 2100ms later; this is not a claim of instantaneous server-side cancellation. No idle transaction remained.

Through the actual browser form, an exclusive lock on the Support case table produced a 503 in 2019ms while retaining the draft. Releasing the actual lock and retrying the unchanged submission saved CASE-002 exactly once; refreshing showed the persisted case. All seven workspace types, shared generation checks, scoped lint/format and backend build passed. No new test code, SQL, grants or purpose activation. This qualifies the local database transaction and browser recovery paths. The host budget does not substitute for a real caller signal or qualify external callbacks, full privacy exports/erasure, native journeys, provider behavior or release acceptance.
