## 1. What we are building

Qelvora gives each creator an authorized, clearly labeled AI that talks one-on-one with every fan,
remembers them and cites the creator's own work.
- **The creator stays present** through signed Notes and reactions, and can step in.
- **Fans can pay for the creator's personal attention:** a signed written reply, charged only if the
  creator accepts.
- **"Who is speaking"** must be answerable in under a second on every surface, with a word, a glyph and
  a color.

The product sources are [docs/BRIEF.md](../BRIEF.md), [docs/source/](../source/) (authoritative) and
[docs/LAUNCH_PLAN.md](../LAUNCH_PLAN.md).

**Launch scope:**
- fans use the native iOS and Android apps, and the web gives the first answer from a link;
- creators use the web Studio on their phones;
- sign-in is option D: Qelvora's own sign-in with Apple and Google, plus an 18+ date-of-birth step;
- the order is a private web alpha (about ten invited adults, Stripe test mode), then TestFlight and Play
  closed testing, then public release after the pilot gates.

## 4. How we work

- **The coordinator** keeps:
  - the plan and this status;
  - the pull request queue and merges;
  - questions for the founder;
  - starting work sessions.

  It writes no feature code.
- **A work session** owns one task, one branch and one pull request.
  - It doesn't edit status docs and doesn't merge.
  - It ends with a report: the PR link, exact check results, what was not checked.
- **Two sessions never write the same files at the same time.**
- **Brief each work session completely,** because it starts from nothing:
  - the task and the files involved;
  - known fixes;
  - the precedents to copy;
  - this Mac's traps (section 8);
  - the rules;
  - what done means.
- **Review before merging.** Send an independent reviewer (a subagent given the code, not your
  conclusion) at anything security-sensitive. On #527 that caught a real gap: the new login was
  checked only at activation. The work session fixed it before the merge.
- **Merging:**
  - merge commits only, after every check passes;
  - integration branches merge the original PR heads (no rebase, no cherry-pick), so GitHub marks the
    originals merged;
  - the app's PR monitor watches CI, and nobody polls it.
- **Evidence:** at most 300 KB per file under `artifacts/` and 1 MB per pull request. Results go in the
  PR description.
- **Rules that never bend:**
  - never reset a used database or device, and reset only stacks the task created;
  - never rewrite applied SQL or publication fingerprints;
  - never invent consent;
  - never advance clocks;
  - never settle an unknown cost without a receipt;
  - INV-01 to INV-25 and the fixed copy are not negotiable;
  - the product name is always Qelvora.

## 8. This Mac

- **gh** is at `/opt/homebrew/bin/gh`, which is not on the default shell PATH.
- **pnpm 12.5.1** is not installed globally. Install it into a scratch folder
  (`npm install --prefix <dir> pnpm@12.5.1`), or once globally.
- **Docker:** its CLI plugins are symlinked into the mounted Docker installer image, which makes
  `docker info` hang.
  - Workaround: point `DOCKER_CONFIG` at a folder whose `config.json` is `{"auths":{}}`, and set
    `DOCKER_HOST=unix:///Users/yp/.docker/run/docker.sock`.
  - Permanent fix: quit Docker, eject the image, and start Docker from Applications.
- **iOS:** Xcode 27.1 with the iOS 27.0 and 27.1 runtimes. Use an iPhone 18 Pro on iOS 27.0, because
  iOS 27.1 offers only the iPhone Duo.
- **Android:** there is no Android SDK here, so CI builds Android.
- **Files tools rewrite.** `swift test` and `xcodebuild` rewrite `apps/ios/Package.resolved`, and
  `next dev` rewrites `apps/web/next-env.d.ts`. Restore both before committing.
- **zsh:**
  - write `${ref}:path`, not `$ref:path` (`:a` and `:h` are modifiers);
  - unquoted variables don't split into words;
  - there is no `timeout` command.
- **Local stack:** `node infra/local/stack.mjs up --lane N --base-port P [--growth] [--no-web]
  [--no-smoke]`.
  - Use fresh stacks for evidence, because a reused stack fails scenarios on leftover state.
  - API URLs take no trailing slash.
  - The lane 6 output folder needs mode 0700.
- **CI** waits mostly on the macOS runner queue: a full run takes 30 to 60 minutes.
