## How work runs now

- **The coordinator** owns:
  - the plan and this status;
  - the pull request queue and merges;
  - questions for the founder;
  - starting work sessions.

  It writes no feature code.
- **A work session** owns one task, one branch and one pull request.
  - It doesn't edit status docs and doesn't merge.
  - It ends with a report: the PR link, exact check results, and what was not checked.
- **One writer per file.** Two sessions never write the same files at the same time.
- **Merging:**
  - merge commits only, after all six "Foundation checks" jobs pass;
  - the app's PR monitor watches CI, and nobody polls it.
- **Integration branches** merge the original PR heads, with no rebase and no cherry-pick, so GitHub marks the originals merged.
- **Evidence stays small:** at most 300 KB per file under `artifacts/` and 1 MB per pull request.
- **Inherited rules:**
  - never reset a used database or device, and reset only stacks the task created;
  - never rewrite applied SQL or publication fingerprints;
  - never invent consent;
  - never advance clocks;
  - never settle an unknown cost without a receipt.
