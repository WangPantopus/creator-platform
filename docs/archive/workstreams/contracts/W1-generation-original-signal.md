# Original generation signal custody

`GenerationIdentityAuthority.originalSignalInTransaction(scope, client)` synchronously returns the exact optional `AbortSignal` retained by the original `withGeneration` call. It requires the genuine issued WeakMap binding, the same held client, its current scope object and the existing non-request worker condition. Cursor refresh retains that binding and signal. The getter issues no SQL, controller, scope or permission; existing durable authorization remains required.

W2 may bookend its actual prepared-input read and pass this same signal to W5's existing optional origin-read seam. An independently unsignaled after-incurred provider settlement remains unsignaled and must not acquire fresh input authority. No generation purpose is activated by this port; current reviewed catalogue and worker configuration are still required.
