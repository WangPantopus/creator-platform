# Support and Ops transaction recovery — October 6, 2026

The Trust API's actor transactions and startup role checks now use the existing original-client settlement helper already used by Trust worker acknowledgments. Checkout must have an actual finite original pool budget. The helper retains the exact client through known rollback or transport close/discard, bounds the whole transaction to five seconds, and refuses uncertain commits. Genuine checkout failures now return a retryable `trust_connection_unavailable` (503) with a private cause.
