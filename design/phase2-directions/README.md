# Phase 2 · visual directions

Source of the canvas [Qelvora Visual Directions](https://claude.ai/artifact/MyZ9H9crjcdKqE196Pk6su)
(a Design canvas on claude.ai). The canvas is the living version; these files are a
snapshot so the work survives outside claude.ai. Each `.dc.html` file is one artboard.

| Direction | Mood | Type | Maya (person) | Maya's AI |

Each direction has five artboards: the thread (AI active), the thread when Maya steps
in, the public creator home, the request packet, and an identity kit (palette with
contrast, the authorship marks, three approved-draft treatments, the other theme, and a
greyscale check). `Main.dc.html` is direction A's thread.
