## Defect and change

Both native settings forms assigned fetched preferences before requesting the creator directory. A directory failure could leave new toggles combined with old or empty quiet-hour fields; a subsequent save could overwrite the server's quiet hours. Both clients now stage the complete response and commit the form only after every read succeeds. Failed reloads retain the prior complete draft, and controls are disabled during requests.

The fields now validate exact ASCII HH:mm from00:00 through23:59, require both boundaries or neither, and validate the device's known time-zone identifiers. Invalid fields receive inline shared copy and focus; Android exposes error/live-region semantics and Swift supplies the field's accessibility hint. Android no longer silently truncates input, and time formatting uses Locale.ROOT. Server validation remains authoritative, including platform alias differences. Request errors preserve the form and use truthful unsaved copy.

One shared English key adds the time-format explanation. The catalog has605 keys, generated by `node scripts/generate-shared.mjs`; existing entries remain unchanged. This is implementation/compilation evidence, not VoiceOver/TalkBack acceptance.
